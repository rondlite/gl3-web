# Premium

Premium unlocks the whole `@gl3-plugins` catalogue: every plugin listed on the
[plugins page](/plugins.html), and everything added to it later.

## Any number of games

The licence is per person, not per server. Run one game or run ten, on your own hardware
or someone else's, and the licence does not change. There is no seat count to track and
no activation step at install time.

## Price

Pricing is still being finalised. [Get in touch](https://github.com/GL3PBBG/GL3/discussions)
to be told when it lands.

## What stays free

The engine itself is open source and always will be. So is the plugin SDK, the shared
types package, and the documentation.

You can run a complete game without buying anything. Premium buys the plugin catalogue,
not the right to play.

## How it works once you have a licence

Once purchasing opens, a licence comes with an npm token for the private registry. Point
npm at it, install the plugins you want, and they load like any other dependency.

```bash
npm install @gl3-plugins/market
```
