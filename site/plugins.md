## Building your own

The plugin SDK is public and free. A plugin owns its own tables and migrations, listens
for typed events, and can add pages, routes and admin sections without patching the
engine.

Start with [Create a plugin](https://docs.gl3.dev/guides/create-a-plugin) in the
documentation.
